# M1 — HTTP Service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the M0 library over HTTP: four endpoints, immutable caching, strict input validation, no identity in logs, and a `--pack` flag that loads a style pack from a file at runtime.

**Architecture:** One Hono app built by a factory (`createApp({ packs })`) so tests drive it through `app.request()` with no socket. A thin CLI parses flags, loads packs, and hands the app to `@hono/node-server`. Packs are an explicit registry passed in, never a global: built-in `organic-blob` plus whatever `--pack` loaded. Nothing is cached server-side — the outputs are pure functions of the URL and take microseconds, so HTTP caching (`ETag` + `Immutable`) is the only cache.

**Tech Stack:** Node 22, Hono 4, `@hono/node-server`, `jiti` 2 (loads `.ts` pack files at runtime), Vitest 2, pnpm workspaces.

**Spec:** `docs/specs/2026-10-27-bot-avatar-spec.md` — §10 (HTTP service), §12 (service acceptance), §13 (M1 exit), §19.3 (`--pack` and `--port`), §20 (pack loadable at runtime).

## Global Constraints

- Node `>=22.22.2`. ESM only in every file.
- `apps/service` is **private** (`"private": true`): it is deployed, not published. It may have runtime dependencies; the three library packages must keep `dependencies` empty.
- Identity: URL-decoded, then 1–200 characters. Empty or longer ⇒ `400`. The limit is measured on the **decoded** string.
- Unknown pack ⇒ `400` with the list of available ids. Unknown route ⇒ `404`.
- Every successful avatar response carries `ETag: "<packId>@<packVersion>:<identityHash>"` and `Cache-Control: public, max-age=31536000, immutable`.
- `If-None-Match` matching the current ETag ⇒ `304` with no body, same ETag and `Cache-Control`.
- The identity must never appear in a log line, an error body, or a metric label — only a short hash prefix.
- `Content-Type`: `image/svg+xml; charset=utf-8` for SVG, `application/json; charset=utf-8` for JSON.
- `size` is an integer 16–1024, default 128. `state` is `idle` or `working`, default `idle`. Bad values ⇒ `400`.
- No server-side response cache. If the benchmark misses its target, that is a finding about computation, not a licence to add a cache.

## Decisions locked before implementation

1. **`--pack` accepts `.ts`** via `jiti` at runtime (`--pack ./my-pack.ts` works with no build step). A pack that fails validation stops startup with a non-zero exit and a message naming the file and the missing field.
2. **ETag hash is SHA-256 of the identity, first 16 hex characters.** Two different identities must not share an ETag; a 32-bit seed would make that a real risk, and the ETag decides what a browser may serve forever.
3. **Identity parsing happens in the handler from `new URL(c.req.url).pathname`**, not from Hono's `:param`. Params are decoded by the framework and the filename suffix has to be stripped from the right; doing both by hand keeps one source of truth and lets identities contain dots (emails) safely.
4. **No `state`/`size` parsing in the library.** The service validates and hands clean values to `renderSvg`.
5. **The service never mutates a pack.** Startup validates it; a load failure exits rather than serving a half-working registry.

```ts
import type { StylePack } from "@botavatar/engine";
import { organicBlob } from "@botavatar/pack-organic-blob";
import { createJiti } from "jiti";
import { isAbsolute, resolve } from "node:path";

export class PackError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "PackError";
  }
}

const REQUIRED = ["id", "name", "version", "viewBox", "shapes", "palette", "eyes", "motion"] as const;

/** Throws unless `candidate` is a usable pack; the message names the origin and the field. */
export function validatePack(candidate: unknown, origin: string): StylePack {
  if (typeof candidate !== "object" || candidate === null) {
    throw new PackError(`${origin}: a pack must be an object`);
  }
  const pack = candidate as Partial<StylePack>;
  for (const field of REQUIRED) {
    if (pack[field] === undefined) throw new PackError(`${origin}: missing ${field}`);
  }
  if (!Array.isArray(pack.shapes) || pack.shapes.length === 0) {
    throw new PackError(`${origin}: shapes must be a non-empty array`);
  }
  if (!Array.isArray(pack.palette) || pack.palette.length === 0) {
    throw new PackError(`${origin}: palette must be a non-empty array`);
  }
  if (!Array.isArray(pack.motion?.durationMsByFamily)) {
    throw new PackError(`${origin}: motion.durationMsByFamily must be an array`);
  }
  if (pack.motion.durationMsByFamily.length !== pack.shapes.length) {
    throw new PackError(
      `${origin}: durationMsByFamily has ${pack.motion.durationMsByFamily.length} entries for ${pack.shapes.length} shapes`,
    );
  }
  if (!Array.isArray(pack.eyes?.eyes) || pack.eyes.eyes.length === 0) {
    throw new PackError(`${origin}: eyes.eyes must be a non-empty array`);
  }
  return pack as StylePack;
}

/** Loads a pack module from disk. Jiti transpiles TypeScript on the fly, so no build step is needed. */
export async function loadPack(path: string): Promise<StylePack> {
  const target = isAbsolute(path) ? path : resolve(process.cwd(), path);
  const jiti = createJiti(import.meta.url);
  let module: unknown;
  try {
    module = await jiti.import(target);
  } catch (error) {
    throw new PackError(`${target}: could not be imported (${(error as Error).message})`);
  }
  const candidate =
    (module as { default?: unknown }).default ??
    (module as { pack?: unknown }).pack ??
    module;
  return validatePack(candidate, target);
}

export function builtinPacks(): StylePack[] {
  return [organicBlob];
}
```

```ts
import type { StylePack } from "@botavatar/engine";
import { createHash } from "node:crypto";

export const CACHE_CONTROL = "public, max-age=31536000, immutable";

/** 16 hex characters of SHA-256: stable across processes, and long enough that two identities never collide. */
export function identityHash(identity: string): string {
  return createHash("sha256").update(identity, "utf8").digest("hex").slice(0, 16);
}

export function etagFor(pack: StylePack, identity: string): string {
  return `"${pack.id}@${pack.version}:${identityHash(identity)}"`;
}

export function errorBody(code: string, message: string, extra: Record<string, unknown> = {}) {
  return { error: { code, message, ...extra } };
}
```

Identity parsing, exported so it can be tested directly:
```ts
/** Splits `/v1/avatar/<identity>.<kind>` from the right, so identities may contain dots. */
export function parseIdentity(pathname: string): { identity: string; kind: "svg" | "json" } | null {
  const prefix = "/v1/avatar/";
  if (!pathname.startsWith(prefix)) return null;
  const rest = pathname.slice(prefix.length);
  const suffix = rest.endsWith(".svg") ? ".svg" : rest.endsWith(".json") ? ".json" : null;
  if (!suffix) return null;
  let decoded: string;
  try {
    decoded = decodeURIComponent(rest.slice(0, -suffix.length));
  } catch {
    return null;
  }
  return { identity: decoded, kind: suffix === ".svg" ? "svg" : "json" };
}
```

The route:
```ts
const MAX_IDENTITY = 200;
const DEFAULT_SIZE = 128;
const MIN_SIZE = 16;
const MAX_SIZE = 1024;

function readSize(raw: string | undefined): number | null {
  if (raw === undefined) return DEFAULT_SIZE;
  const value = Number(raw);
  return Number.isInteger(value) && value >= MIN_SIZE && value <= MAX_SIZE ? value : null;
}

app.get("/v1/avatar/*", (c) => {
  const parsed = parseIdentity(new URL(c.req.url).pathname);
  if (!parsed) return c.json(errorBody("not_found", "no such route"), 404);
  const { identity, kind } = parsed;

  if (identity.length < 1 || identity.length > MAX_IDENTITY) {
    return c.json(errorBody("bad_identity", `identity must be 1-${MAX_IDENTITY} characters`), 400);
  }

  const url = new URL(c.req.url);
  const packId = url.searchParams.get("pack") ?? packs[0]!.id;
  const pack = byId.get(packId);
  if (!pack) {
    return c.json(
      errorBody("unknown_pack", `unknown pack: ${packId}`, { packs: [...byId.keys()] }),
      400,
    );
  }

  const size = readSize(url.searchParams.get("size") ?? undefined);
  if (size === null) {
    return c.json(errorBody("bad_size", `size must be an integer ${MIN_SIZE}-${MAX_SIZE}`), 400);
  }
  const state = url.searchParams.get("state") ?? "idle";
  if (state !== "idle" && state !== "working") {
    return c.json(errorBody("bad_state", "state must be idle or working"), 400);
  }

  const spec = buildAvatarSpec(pack, identity);

  if (kind === "svg") {
    return c.body(renderSvg(spec, { size, state }), 200, {
      "Content-Type": "image/svg+xml; charset=utf-8",
      ETag: etagFor(pack, identity),
      "Cache-Control": CACHE_CONTROL,
    });
  }
  return c.json(spec, 200, { ETag: etagFor(pack, identity), "Cache-Control": CACHE_CONTROL });
});
```

```ts
import { serve } from "@hono/node-server";
import { createApp } from "./app.js";
import { builtinPacks, loadPack, PackError } from "./packs.js";

export interface Args {
  port: number;
  host: string;
  packs: string[];
}

export function parseArgs(argv: string[]): Args {
  const args: Args = { port: 8787, host: "127.0.0.1", packs: [] };
  for (let index = 0; index < argv.length; index++) {
    const flag = argv[index];
    const value = argv[index + 1];
    if (flag === "--pack") {
      if (!value) throw new Error("--pack needs a path");
      args.packs.push(value);
      index++;
      continue;
    }
    if (flag === "--port" || flag === "--host") {
      if (!value) throw new Error(`${flag} needs a value`);
      if (flag === "--host") args.host = value;
      else {
        const port = Number(value);
        if (!Number.isInteger(port) || port < 1 || port > 65535) {
          throw new Error(`--port must be an integer 1-65535, got ${value}`);
        }
        args.port = port;
      }
      index++;
      continue;
    }
    throw new Error(`unknown flag ${flag}`);
  }
  return args;
}

export async function main(argv: string[]): Promise<void> {
  const args = parseArgs(argv);
  const loaded = [];
  for (const path of args.packs) loaded.push(await loadPack(path));
  const packs = [...builtinPacks(), ...loaded];
  const ids = new Set<string>();
  for (const pack of packs) {
    if (ids.has(pack.id)) throw new PackError(`duplicate pack id: ${pack.id}`);
    ids.add(pack.id);
  }

  const app = createApp({ packs, logger: (line) => console.log(line) });
  serve({ fetch: app.fetch, port: args.port, hostname: args.host }, (info) => {
    console.log(`bot-avatar service on http://${args.host}:${info.port} (packs: ${[...ids].join(", ")})`);
  });
}

main(process.argv.slice(2)).catch((error: unknown) => {
  console.error(error instanceof Error ? error.message : String(error));
  process.exitCode = 1;
});
```

```js
const CONCURRENCY = 100;
const REQUESTS = 4000;
const app = createApp({ packs: [organicBlob], logger: () => {} });
const server = serve({ fetch: app.fetch, port: 0, hostname: "127.0.0.1" });

    issued++;
    const started = performance.now();
    const res = await fetch(url);
    await res.arrayBuffer();
    latencies.push(performance.now() - started);

}

server.close();
```
