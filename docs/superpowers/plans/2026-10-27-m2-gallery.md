# M2 — Gallery, PNG and Motion Clips Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a standalone gallery that makes the avatars judgeable by eye, add PNG output to the service, and give the working state a small clip library instead of a single scale pulse.

**Architecture:** The gallery is a Vite + React app that imports the library packages directly — no service, no fetch, so it runs with `pnpm dev` alone. Every wall and detail view is a pure function of URL state, so any view can be shared as a link. PNG lives in the service, not the gallery, because rasterisation is a native dependency that has no business in a browser bundle. Clips are pure keyframe functions in the engine; the pack names a clip per family, the spec carries it, and the SVG renderer emits it as CSS.

**Tech Stack:** Vite 5, React 18, TypeScript 5.6, Vitest 2, `@resvg/resvg-js` for PNG, pnpm workspaces.

**Spec:** `docs/specs/2026-10-27-bot-avatar-spec.md` — §11 (gallery), §12 (gallery acceptance), §13 (M2 exit), §15 (PNG tooling).

## Global Constraints

- The gallery must run with no service and no network: `pnpm --filter @botavatar/gallery dev` is enough.
- Gallery state lives in the URL; reloading a link restores the exact view (`pack`, `ids`, `size`).
- The three library packages keep `dependencies` and `peerDependencies` empty. `apps/gallery` and `apps/service` may take dependencies.
- Determinism is untouched: no gallery code may alter `buildAvatarSpec` output.
- PNG must be produced from the same SVG string the `.svg` route returns, not from a second rendering path.
- Switching packs must not reload the page.
- Every number written into a document comes from a run on the day it is written.

## A spec criterion that cannot pass, and its replacement

§12 says: "对照墙 40 个身份中，`look` 重复率 < 25%". With the shipped pack there are 9 assignable looks (families 0–5, 7, 9; family 8 merges into look 2, family 6 is reserved). For 40 identities the pigeonhole principle forces at least 32 duplicates, so the duplicate rate can never be below (40 − 9) / 40 = 77.5%. Measured on 40 hashed identities: 9 distinct looks, 77.5%. The criterion is unsatisfiable for any N > 9.

Replacement, both reachable and both more informative:

1. **Balance:** every assignable look appears at least once, and no look appears more than `ceil(N / looks)` times. For N = 40 that is ≤ 5 per look. This is what "least-used assignment" actually promises.
2. **Distinctness:** a strip of exactly one identity per look (9 for the shipped pack) must exhibit 9 distinct looks — duplicate rate 0 — which is what a human can actually judge for "these read as different avatars".

The wall shows 40 for browsing; the strip shows the distinctness check. `docs/parity-m0.md`'s siblings should not be edited; this deviation is recorded in `docs/m2-gallery.md` and in the plan's ledger.

`apps/gallery/src/state.ts`:
```ts
export interface WallState {
  pack: string;
  ids: string[];
  size: number;
}

export const DEFAULT_SIZE = 160;
export const MIN_SIZE = 48;
export const MAX_SIZE = 512;
export const MAX_IDS = 60;

export function parseWallState(
  search: string,
  knownPacks: readonly string[],
  fallbackIds: readonly string[],
): WallState {
  const params = new URLSearchParams(search);
  const requestedPack = params.get("pack") ?? "";
  const pack = knownPacks.includes(requestedPack) ? requestedPack : (knownPacks[0] ?? "");

  const rawIds = (params.get("ids") ?? "")
    .split(",")
    .map((entry) => entry.trim())
    .filter((entry) => entry.length > 0);
  const uniqueIds = [...new Set(rawIds)].slice(0, MAX_IDS);
  const ids = uniqueIds.length > 0 ? uniqueIds : [...fallbackIds];

  const parsedSize = Number(params.get("size"));
  const size =
    Number.isInteger(parsedSize) && parsedSize >= MIN_SIZE && parsedSize <= MAX_SIZE
      ? parsedSize
      : DEFAULT_SIZE;

  return { pack, ids, size };
}

export function formatWallState({ pack, ids, size }: WallState): string {
  const params = new URLSearchParams();
  params.set("pack", pack);
  params.set("ids", ids.join(","));
  params.set("size", String(size));
  return `?${params.toString()}`;
}
```

`apps/gallery/src/metrics.ts`:
```ts
import type { AvatarSpec, StylePack } from "@botavatar/engine";
import { avatarAssignableLooks, avatarFamily, avatarLook, avatarSeed } from "@botavatar/engine";

export function lookCounts(specs: readonly AvatarSpec[]): Map<number, number> {
  const counts = new Map<number, number>();
  for (const spec of specs) counts.set(spec.look, (counts.get(spec.look) ?? 0) + 1);
  return counts;
}

export function balance(
  specs: readonly AvatarSpec[],
  assignableLooks: readonly number[],
): { ok: boolean; max: number; allowed: number; missing: number[] } {
  const counts = lookCounts(specs);
  const allowed = Math.ceil(specs.length / Math.max(1, assignableLooks.length));
  const max = Math.max(0, ...counts.values());
  const missing = assignableLooks.filter((look) => !counts.has(look));
  return { ok: max <= allowed && missing.length === 0, max, allowed, missing };
}

export function distinctness(specs: readonly AvatarSpec[]): {
  distinct: number;
  total: number;
  rate: number;
} {
  const distinct = new Set(specs.map((spec) => spec.look)).size;
  const total = specs.length;
  return { distinct, total, rate: total === 0 ? 0 : (total - distinct) / total };
}

/**
 * Identities whose looks are spread as evenly as the pack allows: walk the
 * assignable looks round-robin, and for each look take the next identity whose
 * hash lands on it. Deterministic, so a shared link reproduces the same wall.
 */
export function wallIdentities(pack: StylePack, count: number): string[] {
  const looks = avatarAssignableLooks(pack.shapes);
  const ids: string[] = [];
  const used = new Map<number, number>();
  for (let slot = 0; ids.length < count; slot++) {
    const target = looks[slot % looks.length]!;
    const attempt = used.get(target) ?? 0;
    const id = identityWithLook(pack, target, attempt);
    used.set(target, attempt + 1);
    if (!ids.includes(id)) ids.push(id);
    if (slot > count * 50) break;
  }
  return ids.slice(0, count);
}

function identityWithLook(pack: StylePack, look: number, ordinal: number): string {
  let seen = 0;
  for (let index = 0; ; index++) {
    const identity = `wall-${look}-${index}`;
    const family = avatarFamily(avatarSeed(identity), pack.shapes);
    if (avatarLook(family, pack.shapes) !== look) continue;
    if (seen === ordinal) return identity;
    seen++;
  }
}
```

`balance` takes the pack's assignable looks rather than a count: `missing` has to be measured against the looks the pack can actually produce, not against the looks a given wall happens to contain.

import type { StylePack } from "@botavatar/engine";
import { organicBlob } from "@botavatar/pack-organic-blob";
import { clay } from "./packs/clay.js";

const local = import.meta.glob<{ default: StylePack }>("./packs/*.ts", { eager: true });

export function galleryPacks(): Array<{ pack: StylePack; label: string }> {
  const builtin = [{ pack: organicBlob, label: organicBlob.name }];
  const extra = Object.entries(local)
    .map(([path, module]) => ({
      pack: module.default,
      label: `${module.default.name} (${path.split("/").pop()?.replace(/\.ts$/, "")})`,
    }))
    .filter((entry) => entry.pack.id !== organicBlob.id);
  const seen = new Set<string>();
  return [...builtin, ...extra].filter((entry) => {
    if (seen.has(entry.pack.id)) return false;
    seen.add(entry.pack.id);
    return true;
  });
}

`packages/engine/src/clips.ts`:
```ts
export type ClipName = "breathe" | "bob" | "sway" | "bounce" | "tilt" | "shake" | "blink" | "look-round";

export const CLIP_NAMES: readonly ClipName[] = [
  "breathe",
  "bob",
  "sway",
  "bounce",
  "tilt",
  "shake",
  "blink",
  "look-round",
];

export interface ClipFrame {
  translateY: number;
  scale: number;
  rotate: number;
  eyeScaleY: number;
  eyeOffsetX: number;
}

/** A loop whose endpoints are at rest, so it can repeat without a seam. */
export function clipFrame(clip: ClipName, progress: number, amplitude: number): ClipFrame {
  const at = Math.max(0, amplitude);
  const mid = (1 - Math.cos(progress * Math.PI * 2)) / 2;
  const swing = Math.sin(progress * Math.PI * 2);
  const frame: ClipFrame = { translateY: 0, scale: 1, rotate: 0, eyeScaleY: 1, eyeOffsetX: 0 };

  switch (clip) {
    case "breathe":
      frame.scale = 1 + 0.04 * at * mid;
      break;
    case "bob":
      frame.translateY = -5 * at * mid;
      break;
    case "sway":
      frame.rotate = 5 * at * mid;
      break;
    case "tilt":
      frame.rotate = 3 * at * swing;
      frame.translateY = -1.5 * at * mid;
      break;
    case "bounce":
      frame.translateY = -6 * at * mid;
      frame.scale = 1 + 0.05 * at * Math.sin(progress * Math.PI * 2);
      break;
    case "shake":
      frame.translateY = 1.5 * at * Math.sin(progress * Math.PI * 6);
      break;
    case "blink":
      // Closed at the midpoint, open at both ends; the amplitude narrows the gap.
      frame.eyeScaleY = Math.max(0, 1 - at * (1 - Math.cos(progress * Math.PI * 2)) / 2);
      break;
    case "look-round":
      frame.eyeOffsetX = 5 * at * swing;
      break;
  }
  return frame;
}
```
