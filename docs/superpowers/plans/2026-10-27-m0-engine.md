# M0 — Avatar Engine, Organic Blob Pack, SVG Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a standalone, dependency-free TypeScript library that turns any identity string into a stable `AvatarSpec` and an SVG string, verified against a one-time snapshot of the upstream rendering.

**Architecture:** Four layers, strictly separated. `@botavatar/engine` owns hashing, family/look selection, colour choice, outline deformation and the spec builder — pure functions, zero dependencies. `@botavatar/pack-organic-blob` contributes data only (10 outlines, 11 colours, eye geometry, durations). `@botavatar/svg` turns a spec into a string and knows nothing else. Upstream is a read-only reference used once to record golden fixtures; after M0 the fixtures are frozen history, not a CI gate.

**Tech Stack:** TypeScript 5.6, pnpm 9.15 workspaces, Vitest 2, tsup (ESM + d.ts), Node 22.

**Spec:** `docs/specs/2026-10-27-bot-avatar-spec.md` (this plan implements §13 milestone M0 only).

## Global Constraints

- ESM only. Every package sets `"type": "module"` and exports `import` + `types`.
- `dependencies` must be empty in every published package; `peerDependencies` empty. Dev tooling lives at the root.
- Engine and renderer never call `Date.now()`, `Math.random()`, `crypto.randomUUID()`, or read `window`/`process`.
- No brand strings. `rakazo`, `shoalwork`, `Rakazo`, `ShoalWork` must not appear in any `src/` file, in any generated SVG, or in any committed fixture key.
- Same `(pack version, identity)` ⇒ byte-identical `AvatarSpec` and SVG, across processes and platforms.
- Bundle budget: `@botavatar/engine` and `@botavatar/svg` each < 20 KB gzip, excluding the pack package.
- Licence Apache-2.0, with a `NOTICE` recording the derivation. Upstream commit for all golden data: `a0e5781`.
- Node `>=22.22.2`. Package scope: `@botavatar/*`.

## Contract deviations from the spec (deliberate, recorded here)

Four places where the spec's §5 contract cannot be implemented as literally written. Each is load-bearing; do not "fix" them back.

1. **`AvatarSpec.viewBox: string` is added.** The spec's `AvatarSpec` has no viewport, but §6 invariant 6 says the renderer depends on the spec only. Without `viewBox` on the spec the renderer would need the pack. Added field, one line.
2. **`ShapeFamily.smoothingPasses?: number` is added.** Upstream hardcodes "families 3–5 get 1 pass, the rest get 2". That rule is pack knowledge, not engine knowledge: a 6-shape pack would break it. The engine reads the field (default 2) and never inspects family indices.
3. **`reserved` is an assignment-time exclusion, not a remap.** Spec §6 invariant 3 says reserved families are never assigned. Upstream reaches that by *choosing ids* whose hash avoids the reserved family (`chooseBotAvatar`), never by rewriting `seed % 10`. Remapping inside `avatarFamily` would change the distribution and diverge from upstream. So: `avatarFamily` stays pure hash; `avatarAssignableLooks(pack)` excludes reserved; `pickLeastUsed` only ever receives the assignable set.

4. **`StylePack.surface?: Surface` is added.** A pack may describe material — multi-stop ink, a highlight, a drop shadow, grain — instead of a two-stop gradient. Absent, the renderer falls back to `light`/`dark`, so `organic-blob` renders exactly as a flat pack would. This is the vocabulary a skeuomorphic pack needs; a Pixar-grade look needs a different renderer, not a bigger spec (see Known gaps).

Also recorded: **"byte-identical" means spec-level equality, not SVG string equality.** Upstream's React component derives gradient ids from `useId`, so its serialized markup cannot be compared literally. Parity compares `seed`, `family`, `look`, `path`, `eyeRotation`, `durationMs`, `color.id` — the values the renderer consumes.

- [ ] **Step 1: Write the recorder**

`parity/record.mjs`:
```js
import { execFileSync } from "node:child_process";
import { mkdirSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";

const upstream = process.env.UPSTREAM_DIR;
if (!upstream) throw new Error("set UPSTREAM_DIR to a rakazo checkout");

const commit = execFileSync("git", ["-C", upstream, "rev-parse", "--short", "HEAD"], {
  encoding: "utf8",
}).trim();

const core = await import(
  pathToFileURL(join(upstream, "packages/core/src/avatar-shape.ts")).href
);

const identities = [
  ...Array.from({ length: 100 }, (_, index) => `fixture-${index}`),
  ...Array.from({ length: 10 }, (_, family) => core.organicAvatarSampleIdentity(family)),
];

const rows = identities.map((identity) => {
  const seed = core.avatarIdentitySeed(identity);
  const family = core.organicAvatarFamily(identity);
  return {
    identity,
    seed,
    family,
    look: core.organicAvatarLook(family),
    path: core.organicAvatarPath(seed),
  };
});

const out = join(dirname(fileURLToPath(import.meta.url)), "fixtures/upstream.json");
mkdirSync(dirname(out), { recursive: true });
writeFileSync(out, `${JSON.stringify({ source: "rakazo", commit, rows }, null, 0)}\n`);

console.log(`recorded ${rows.length} rows from ${commit} -> ${out}`);
```

- [ ] **Step 4: Write the seed**

`packages/engine/src/seed.ts`:
```ts
/**
 * The shape seed for an identity: `hash * 31 + charCode`, truncated to 32 bits.
 * Kept bit-exact with the upstream formula so recorded fixtures stay valid.
 */
export function avatarSeed(identity: string): number {
  let hash = 0;
  for (let index = 0; index < identity.length; index++) {
    hash = (hash << 5) - hash + identity.charCodeAt(index);
    hash |= 0;
  }
  return Math.abs(hash);
}
```

Note: `(hash << 5) - hash` is `hash * 31`. Do not "simplify" it to `hash * 31` — the `| 0` truncation happens per character and the two differ for long inputs.

import type { ShapeFamily } from "./spec.js";

/** The family an identity hash lands on: `seed % shapes.length`. */
export function avatarFamily(seed: number, shapes: readonly ShapeFamily[]): number {
  return seed % shapes.length;
}

/** The visual identity of a family, merging families a pack declares equivalent. */
export function avatarLook(family: number, shapes: readonly ShapeFamily[]): number {
  return shapes[family]?.look ?? family;
}

/** Looks a new identity may be assigned: reserved families removed, duplicates merged. */
export function avatarAssignableLooks(shapes: readonly ShapeFamily[]): number[] {
  const looks = new Set<number>();
  for (let family = 0; family < shapes.length; family++) {
    if (shapes[family]?.reserved) continue;
    looks.add(avatarLook(family, shapes));
  }
  return [...looks].sort((a, b) => a - b);
}
```

**Interfaces:**

type Point = readonly [number, number];

/** Upstream spreads the seed over one turn to distort each body slightly. */
export function phaseForSeed(seed: number): number {
  return ((seed % 360) * Math.PI) / 180;
}

const round = (value: number): number => Math.round(value * 100) / 100;

/**
 * Turns a polygon into an SVG path: affine distortion from the phase, then
 * Chaikin smoothing, then Catmull-Rom control points.
 *
 * Bit-exact with the upstream implementation: every emitted number is rounded,
 * and the smoothing runs before the curve, not after.
 */
export function outlinePath(
  outline: ReadonlyArray<Point>,
  { phase, smoothingPasses = 2 }: { phase: number; smoothingPasses?: number },
): string {
  const xScale = 1 + Math.sin(phase) * 0.035;
  const yScale = 1 + Math.cos(phase) * 0.025;
  const shear = Math.sin(phase * 1.7) * 0.025;

  let points = outline.map(([x, y]) => ({ x: x * xScale + y * shear, y: y * yScale }));

  for (let pass = 0; pass < smoothingPasses; pass++) {
    points = points.flatMap((point, index) => {
      const next = points[(index + 1) % points.length]!;
      return [
        { x: point.x * 0.75 + next.x * 0.25, y: point.y * 0.75 + next.y * 0.25 },
        { x: point.x * 0.25 + next.x * 0.75, y: point.y * 0.25 + next.y * 0.75 },
      ];
    });
  }

  const count = points.length;
  const first = points[0]!;
  let path = `M${round(first.x)} ${round(first.y)}`;
  for (let index = 0; index < count; index++) {
    const before = points[(index - 1 + count) % count]!;
    const current = points[index]!;
    const next = points[(index + 1) % count]!;
    const after = points[(index + 2) % count]!;
    path +=
      `C${round(current.x + (next.x - before.x) / 6)} ${round(current.y + (next.y - before.y) / 6)}` +
      ` ${round(next.x - (after.x - current.x) / 6)} ${round(next.y - (after.y - current.y) / 6)}` +
      ` ${round(next.x)} ${round(next.y)}`;
  }
  return `${path}Z`;
}
```

const FNV_OFFSET = 2166136261;
const FNV_PRIME = 16777619;
const GOLDEN = 2654435769;

/** 32-bit FNV-1a. Separate from `avatarSeed` on purpose; see the plan's Task 7 note. */
export function fnv1a(value: string): number {
  let hash = FNV_OFFSET;
  for (let index = 0; index < value.length; index++) {
    hash = Math.imul(hash ^ value.charCodeAt(index), FNV_PRIME);
  }
  return hash >>> 0;
}

/** SplitMix32, returning a generator of uniforms in [0, 1). */
function uniform(seed: number): () => number {
  let value = seed >>> 0;
  return () => {
    value = (value + 1831565813) | 0;
    let next = Math.imul(value ^ (value >>> 15), 1 | value);
    next = (next + Math.imul(next ^ (next >>> 7), 61 | next)) ^ next;
    return ((next ^ (next >>> 14)) >>> 0) / 4294967296;
  };
}

/** Which palette entry an identity wears. */
export function colorIndex(identity: string, count: number): number {
  const seed = (fnv1a(identity) ^ Math.imul(1, GOLDEN)) >>> 0;
  return Math.floor(uniform((seed ^ GOLDEN) >>> 0)() * count);
}

import { avatarFamily } from "./family.js";
import { avatarSeed } from "./seed.js";
import type { StylePack } from "./spec.js";

/** A uniform number in [0, 1). Injected so the engine itself stays deterministic. */
export type Random = () => number;

/**
 * One of the options `used` relies on least, chosen at random among ties,
 * preferring anything missing from `avoid`.
 */
export function pickLeastUsed<T>(
  options: readonly T[],
  used: readonly T[],
  random: Random,
  avoid: readonly T[] = [],
): T {
  const counts = options.map((option) => used.filter((value) => value === option).length);
  const fewest = Math.min(...counts);
  const least = options.filter((_, index) => counts[index] === fewest);
  const preferred = least.filter((option) => !avoid.includes(option));
  const candidates = preferred.length > 0 ? preferred : least;
  return candidates[Math.floor(random() * candidates.length)] ?? options[0]!;
}

/** A stable identity whose hash lands on `family`, for previews before an id exists. */
export function avatarSampleIdentity(pack: StylePack, family: number): string {
  for (let index = 0; ; index++) {
    const identity = `look-${family}-${index}`;
    if (avatarFamily(avatarSeed(identity), pack.shapes) === family) return identity;
  }
}

`packages/renderer-svg/src/index.ts`:
```ts
import type { AvatarSpec } from "@botavatar/engine";

export interface RenderOptions {
  size: number;
  state?: "idle" | "working";
}

export interface AvatarRenderer<Out> {
  render(spec: AvatarSpec, options: RenderOptions): Out;
}

const escapeAttribute = (value: string): string =>
  value.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");

function gradientId(spec: AvatarSpec): string {
  // Derived from the spec, so two renders of one spec agree; sanitised, so a
  // pack id cannot break out of the attribute.
  return `av-${escapeAttribute(`${spec.packId}-${spec.seed}`)}`.replace(/[^A-Za-z0-9_-]/g, "-");
}

function eyeMarkup(spec: AvatarSpec): string {
  return spec.eyes
    .map((eye) =>
      eye.kind === "rect"
        ? `<rect x="${eye.x}" y="${eye.y}" width="${eye.width}" height="${eye.height}" rx="${eye.rx}" />`
        : `<ellipse cx="${eye.cx}" cy="${eye.cy}" rx="${eye.rx}" ry="${eye.ry}" />`,
    )
    .join("");
}

function workingStyle(spec: AvatarSpec, id: string): string {
  return (
    `<style>@keyframes ${id}-work{0%,100%{transform:scale(1)}50%{transform:scale(1.04)}}` +
    `.${id}-body{transform-origin:center;animation:${id}-work ${spec.durationMs}ms ease-in-out infinite}` +
    `@media (prefers-reduced-motion: reduce){.${id}-body{animation:none}}</style>`
  );
}

/** The ink gradient: the pack's material stops when it has any, otherwise light to dark. */
function fillDefs(spec: AvatarSpec, id: string): string {
  const stops = spec.surface?.stops;
  const ink = stops?.length
    ? stops
        .map(
          (stop) =>
            `<stop offset="${stop.offset * 100}%" stop-color="${escapeAttribute(stop.color)}" />`,
        )
        .join("")
    : `<stop offset="0%" stop-color="${escapeAttribute(spec.color.light)}" />` +
      `<stop offset="100%" stop-color="${escapeAttribute(spec.color.dark)}" />`;
  return `<linearGradient id="${id}-fill" x1="0" y1="0" x2="1" y2="1">${ink}</linearGradient>`;
}

function highlight(spec: AvatarSpec, id: string): { defs: string; shape: string } {
  const shine = spec.surface?.highlight;
  if (!shine) return { defs: "", shape: "" };
  return {
    defs:
      `<radialGradient id="${id}-shine" cx="50%" cy="50%" r="50%">` +
      `<stop offset="0%" stop-color="#FFFFFF" stop-opacity="${shine.opacity}" />` +
      `<stop offset="100%" stop-color="#FFFFFF" stop-opacity="0" />` +
      `</radialGradient>`,
    shape: `<ellipse cx="${shine.cx}" cy="${shine.cy}" rx="${shine.r}" ry="${shine.r}" fill="url(#${id}-shine)" />`,
  };
}

function shadowDefs(spec: AvatarSpec, id: string): string {
  const shadow = spec.surface?.shadow;
  if (!shadow) return "";
  return (
    `<filter id="${id}-shadow" x="-40%" y="-40%" width="180%" height="180%">` +
    `<feDropShadow dx="${shadow.dx}" dy="${shadow.dy}" stdDeviation="${shadow.blur}"` +
    ` flood-color="${escapeAttribute(shadow.color)}" />` +
    `</filter>`
  );
}

/** The four numbers of the viewBox, in the order x, y, width, height. */
function viewport(spec: AvatarSpec): [number, number, number, number] {
  const parts = spec.viewBox.trim().split(/\s+/).map(Number);
  return [parts[0] ?? -60, parts[1] ?? -60, parts[2] ?? 120, parts[3] ?? 120];
}

function grainMarkup(spec: AvatarSpec, id: string): string {
  const texture = spec.surface?.texture;
  if (!texture || texture.kind === "none") return "";
  const [x, y, width, height] = viewport(spec);
  return (
    `<filter id="${id}-grain"><feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="3" />` +
    `<feColorMatrix type="saturate" values="0" /></filter>` +
    `<rect x="${x}" y="${y}" width="${width}" height="${height}"` +
    ` filter="url(#${id}-grain)" opacity="${texture.opacity}" />`
  );
}

/** Renders a spec to a standalone SVG string. No DOM, no globals. */
export function renderSvg(spec: AvatarSpec, { size, state = "idle" }: RenderOptions): string {
  const pixels = Math.max(1, Math.round(size));
  const id = gradientId(spec);
  const working = state === "working";
  const shine = highlight(spec, id);
  const shadowed = spec.surface?.shadow ? ` filter="url(#${id}-shadow)"` : "";

  return (
    `<svg xmlns="http://www.w3.org/2000/svg" viewBox="${escapeAttribute(spec.viewBox)}"` +
    ` width="${pixels}" height="${pixels}" aria-hidden="true">` +
    (working ? workingStyle(spec, id) : "") +
    `<defs>${fillDefs(spec, id)}${shine.defs}${shadowDefs(spec, id)}</defs>` +
    `<g${working ? ` class="${id}-body"` : ""}${shadowed}>` +
    `<path d="${escapeAttribute(spec.path)}" fill="url(#${id}-fill)" />` +
    shine.shape +
    `<g transform="rotate(${spec.eyeRotation})" fill="${escapeAttribute(spec.color.eye)}">` +
    eyeMarkup(spec) +
    `</g></g>` +
    grainMarkup(spec, id) +
    `</svg>`
  );
}

export const svgRenderer: AvatarRenderer<string> = { render: renderSvg };
```
