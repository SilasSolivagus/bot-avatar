# 修正：参考实现是扁平的，不是体积化的

日期：2026-10-28　状态：决定（推翻本目录中"体积/光照"方向）
相关：`2026-10-28-eye-rig-absorption.md`、`2026-10-28-contract-v2.md`

## 0. 一句话

我们花了两轮讨论"身体该不该有体积、要不要按法线打光"。答案是不该——**参考实现的头像是一块单色剪影，靠球面眼睛和形状变形获得生命感，不靠光照**。

## 1. 依据（原文与实测）

xAI 官方设计文对构造的描述：

> **The body is a single dark filled silhouette (`#0a0a0c`), and the face is just two light capsule-shaped eyes.** All expression comes from eye shape, tilt, and position.

bloub 的测量文档补充：

> **The body at rest is a perfect circle** — not a squircle. Measured radial deviation is under 0.7%.

而线上 CSS 是两组纯色绑定，没有任何渐变或滤镜：

```css
._2wE0bW_head { fill: var(--fg); }
._2wE0bW_eye  { fill: var(--bg); }
```

实测截图同样如此：橙色、深棕色都是**平涂色块**，边缘干净，没有明暗过渡。更能说明问题的是六边形那一版——**六边形整体倾斜，眼睛以同样的角度倾斜**。也就是说，"转头"就是**整组平面旋转**。

## 2. 结论

| 维度 | 参考实现 | 我们此前的方案 | 采信 |
| --- | --- | --- | --- |
| 身体填充 | 单色平涂 | 两段渐变 | 改：墨模式用单色，渐变只保留给现有包 |
| 体积/法线光照 | 没有 | 提议做 metaball + 法线光照 | **作废** |
| 挤出/厚板 | 没有 | 提议 extruded card | **作废** |
| 转头 | 整组平面旋转 | 已实现（`bodyCoupling`） | 保留 |
| 3D 感来源 | 眼睛的球面投影 | 已实现 | 保留 |
| 眼睛 | `<mask>` 挖空 | 实心色块 | 改：挖空 |
| 状态差异 | 剪影变形（egg/hex/三角等）+ 眨眼遮盖 | 整体位移/缩放 | 改：轮廓插值 |

**体积感来自形状圆、眼睛在球面上、剪影会变形，而不是来自光照。**

## 3. 要做三件事

### 3.1 墨模式（flat ink）

- `Ink.body = "ink"` 时，身体填充**一个颜色**：网页里是 `currentColor`，服务端渲染必须显式传色。
- 眼睛 `ink.eyes = "surface"` 时**挖空**，透出背景；服务端必须传 `bg`。
- 现有 `organic-blob` 保持渐变（它是另一个风格方向），不改输出。

### 3.2 眼睛挖空

用 `<clipPath>` 或 `<mask>` 把眼睛裁进轮廓，解决 45° 出界。同时保证：身体旋转时裁剪跟着转（组内裁剪）。

### 3.3 形状变形

- `ShapeFamily.outlineTurn?: { left: Point[]; right: Point[] }`：可选，作者提供转过去的样子。
- 两个轮廓点数不同时先重采样到固定数量（**仅适用于相对中心星形的形状**；非星形退化为"眨眼遮盖 + 直接切换"）。
- 变形一律用眨眼遮住：先闭眼，换轮廓，再睁眼。

## 4. 明确作废的方向

以下都写下来，避免以后有人再提：

| 方向 | 作废理由 |
| --- | --- |
| metaball / 隐式曲面 | 参考实现是平面矢量；引入体积会变成另一种风格，且服务端与 SVG 都要重写 |
| 挤出体 + 侧壁 | 一旦转动，"前后两片分开"，观感比平面旋转更差 |
| 法线光照（`feDiffuseLighting`） | 参考实现没有光照；加上去会与 UI 的扁平语言打架 |
| 三维渲染管线 | 只在做"毛绒球"那种另一条产品线时才需要，与当前风格无关 |

## 5. 对既有文档的影响

- `2026-10-28-contract-v2.md` §3 里 `Body.depth` 的设想**不再采用**；`Body` 保持 `outline + phase + smoothingPasses + curve + viewBox`。
- `2026-10-28-eye-rig-absorption.md` 第 7 节"材质"只适用于非墨模式的自定义包，不是主线。
- 之前那两张演示图（挤出星、光照球）是**反例**，不是目标形态。

## 6. 三条落定规则

1. **脸部参数由轮廓推导。** `deriveFace(outline)` 量出正面 ±50° 内的最小半径 `rMin`，眼睛的大小、间距和竖直锚点（`anchorY`）全部由它决定。包作者不写眼宽、眼距和锚点，写了也会被 `buildGeometry` 覆盖；换物种只换轮廓。
2. **眼睛端头是半圆胶囊。** 球面投影只分解成旋转和两个半轴，本地坐标下画一个 `rx = 半宽` 的 `rect`，再只施加 `rotate` 与 `translate`。不得把投影矩阵直接压在 `rect` 上——那会把半圆端头压成椭圆。
3. **静止倾斜同向。** `restTiltDeg`（默认 −4°）对两只眼睛取同一个值，静止时两眼平行；镜像倾斜只留给表情，不能作为静止形态。
