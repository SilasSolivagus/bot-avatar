# 吸收清单：从 Grok Bot 头像系统里取什么

日期：2026-10-28　状态：设计输入（尚未实现）
来源：xAI 官方设计文 + bloub 逐帧还原的架构/测量/源码（MIT，仅代码；数值所编码的 x.ai 角色设计不在 MIT 覆盖范围内）

## 1. 最反直觉的一条：眼睛不是颜色，是洞

xAI 线上 CSS：

```css
._2wE0bW_head { fill: var(--fg); }
._2wE0bW_eye  { fill: var(--bg); }
```

`--bg` 在挂载时绑定到侧栏 / 面板 / 看板 / 纸面之一。深色主题下侧栏是 `#242424`，浅色是 `#f7f7f7`。

**规则恒定：身体永远用"墨"，眼睛永远用"表面色"。** 看起来的反转只是两个令牌换值。

代价：因为"眼缝"是用表面色描边填的（不是真挖空），**头像是不透明的，不能叠在图片上**。

对我们的选择：

- `paint: "hole"` —— 身体 `currentColor`、眼睛真挖空（mask）。一个 SVG 自动适配任何界面；**但 PNG 与服务端渲染必须显式传背景色**。
- `paint: "ink"` —— 保持今天的做法：身体渐变、眼睛画上颜色。服务端自足，但不随主题变。

建议：**两者都要**，由 pack 声明，默认保持 `ink`（不改变已发布包的行为）。

## 2. 眼睛长在球面上：要抄的是投影，不是数字

测量结论：远离中心的那只眼睛宽度约为另一只的 **0.674**，面积 **0.663**。面积/宽度 ≈ **0.984**，说明压缩**只发生在水平轴**——这是正交投影下切平面渲染的特征；各向同性缩放会得到 0.454，已被排除。

源码里的实现：每只眼睛是球面切平面上的胶囊，取切平面基向量，正交投影后直接输出成 SVG 的 `matrix(...)`。压缩、倾斜、转到脑后消失，都是投影的副产品。

源码常量（仅供理解量级，**不要照抄**）：胶囊半轴 `w=0.186·R`、`h=0.412·R`；两眼半分离角 `15.46°`；`R=100` 对应 ±158 的 viewBox。

静止时束角约 **26°**，且**不是常量**——从静止注视方向经切平面自然得出。把它写死会与注视方向脱节。

### 我们该抄的

- 眼睛位置由 `(yaw, pitch)` 经正交投影得出，输出一个 2×2 矩阵 + 位移
- 眨眼是**屏幕竖直方向的压扁**，且发生在倾斜**之后**（他们的 `0.06 + 0.94·lid`）
- 深度衰减与剔除（`depth ≈ 0.12` 开始淡出，`0.02` 剔除）

### 我们不该抄的

- `REST_GAZE` 的具体角度（28.49 / 28.62 / −13）
- 逐帧描出来的 egg / hexagon / triangle 轮廓
- 16 行表情表、装饰物常量

## 3. 每个剪影自带脸部锚点

`tn.wedge.face.leftDX = -6` —— 眼睛位置是**每个形状单独写死的**。

理由很硬：用包围盒推导，在**不对称形状上会歪**。

对我们：`ShapeFamily` 需要可选的 `face` 锚点字段。没有它，我们的 pack 作者只能靠试。

## 4. 在构建期算成表，不要逐帧求解

他们为了让眼睛不顶出轮廓，算了**一张偏移表**（`eyefit.ts`，导入时一次）。之前**七版在渲染循环里实时求解，全部抖动**，失败模式都有名字：

- 最近边缘切换 → active-set change，26 单位回跳
- `min` 只连续不可导 → 非光滑目标
- 逐帧反馈 → chattering

这套做法在角色绑定里有名字：**pose space deformation**（Lewis, Cordner & Fong, SIGGRAPH 2000）。

对我们：这和我们"启动时穷举校验、运行时不求解"的做法是同一个哲学，可以直接借。

## 5. 状态是姿态 + 正弦，不是关键帧

- 他们有约 40 个动画状态，对外只暴露 6 个生命周期状态，中间是**别名层**
- 状态由**每通道独立的正弦**叠加，频率故意不谐和：`idle: 1.5·sin(.5r) + .6·sin(.17r)`、`thinking: -9 + 5·sin(.35r)`、`working: 4 + 2.5·sin(r·π·3.2)`
- 每个状态还带**一组表情变体**，不是一张固定的脸
- 形状切换一律用眨眼遮住：强制眨眼 0.2s，定时眨眼 0.18s
- 缓动是测出来的指数缓出，**身体永不过冲**；唯一的弹簧是角标 +14%

对我们：静态 SVG 渲染不了正弦，但可以

- 用 `posterAt(state)` 取一帧确定的姿态作为静图（**这是我们必须新增的东西**）
- 动态图把正弦采样成 8–12 个关键帧，CSS 播放

## 6. 静止时不飘

测量：静止时中心稳定在 ±0.003（球半径的比例）。他们**故意保留**一丝漂移（千分之几）和 0.5% 的呼吸，"纯粹为了画面不完全冻住"。

原文告诫：**不要在静止叠加浮动**。生命感来自注视漂移和眨眼。

## 7. 两条与动画无关、但静态图也必须遵守的规则

- **倾角只在长眼睛上可见**：长宽比必须落在 `[0.6, 1.7]` 之外（倾角 ≥20°），或 `[0.8, 1.25]` 之外（更小倾角）。接近圆形时任何倾斜都看不出来
- **两套墨色令牌**：界面色（`--ink`）与头像墨（`#0a0a0c`）互不联动。合并成一个，换主题时会连带改掉头像

## 8. 明确不采纳

| 项 | 原因 |
| --- | --- |
| 逐帧 sample(t)、指针注视、60fps 状态机 | 我们产出的是静态字符串，不是常驻动画 |
| 14 个状态的目录、装饰物、描边宽度 | 品牌专属；MIT 只覆盖代码，不覆盖数值编码的设计 |
| 不透明底衬（用表面色描边填眼缝） | 那是他们无法挖空时的折衷；我们可以真挖空 |
| 以包围盒推导眼睛位置 | 不对称形状会歪 |

## 9. 建议的实现顺序

1. **眼睛器官**：`EyeRig` 进 spec（胶囊 + 分离角 + 注视角），渲染器输出矩阵与 mask；`paint: "ink" | "hole"`。默认保持今天的两个矩形，输出不变。
2. **每形状脸部锚点**：`ShapeFamily.face`，缺省居中。
3. **姿态表**：`posterAt(state)` 与状态枚举，先给 3 个状态（idle / thinking / working）。
4. **墨模式包**：`ink` 构造，`currentColor` 身体 + 挖空眼睛，证明同一引擎能画出"相反明暗"的一套。
